# Globale Regeln
- IMMER überprüfen, ob eine neue UI-Komponente sowohl im Light Mode (Hellmodus) als auch im Dark Mode (Dunkelmodus) korrekt und gut aussieht.
- IMMER sicherstellen, dass alle Texte (Buttons, Labels, Alerts, Platzhalter) in allen 5 unterstützten Sprachen (Deutsch, Englisch, Persisch, Arabisch, Türkisch) lokalisiert sind.
